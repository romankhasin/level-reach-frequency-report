# Level Reach & Frequency Report

Отдельный модуль Level Digital Hub для анализа дедуплицированного охвата и частоты по данным Target Ads.

## Структура отчёта

- Level Group Total
- проекты Level Group
- для каждого проекта — собственные Reach, Frequency и показы

Reach считается по уникальным `InteractionDeviceID` отдельно на каждом уровне. Охваты строк не суммируются.

Доступные периоды: июль, полный август и полный сентябрь 2026. В интерфейсе период
переключается без смешения JSON-данных.

В сентябрьском отчёте каждое активное размещение перечислено отдельно и
сверено с итогами по группам и общим числом показов. Нераспознанные кампании
показаны в отдельном разделе, а не скрыты из интерфейса.

Разбивка по медиаканалам в интерфейсе не используется.
